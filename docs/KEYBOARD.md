# Keyboard shortcuts

## Global
| Key | Action |
| --- | --- |
| `Space` | Play / pause |
| `F11` / `F` | Toggle fullscreen |
| `Esc` | Exit fullscreen |
| `Double-click video` | Toggle fullscreen |
| `S` | Toggle shuffle |
| `L` | Toggle loop |
| `M` | Mute / unmute |
| `H` | Show keyboard help |
| `,` / `.` | Previous / next frame (step) |
| `Left` / `Right` | Seek −5s / +5s |
| `Shift+Left` / `Shift+Right` | Previous / next track |
| `Up` / `Down` | Volume ±5% |
| `PageUp` / `PageDown` | Volume ±10% |
| `[` / `]` | Speed − / + (fine) |
| `{` / `}` | Speed half / double |
| `Backspace` | Reset speed to 1× |

## Fullscreen
| Mouse | Action |
| --- | --- |
| Move | Reveal cursor + controls (auto-hide after ~3.5s) |
| Hover bottom band | Reveal controls |
| Click seek bar | Jump to position |

Shortcuts follow mpv conventions where they overlap. Some are handled by mpv
itself (frame-step, seeking) when the video has focus.
